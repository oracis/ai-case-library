# 用 AI 识别虫咬类型，一个 App 的订阅生存之道

## 低频高焦虑需求的精准定位
拍照识别虫咬类型的 iOS 应用：给出可能的虫种、置信度、护理建议，并记录咬痕随时间的变化。免费下载，核心功能靠内购订阅解锁。

## 置信度表达优于强行给答案
免费下载 + 内购订阅（Go Pro 解锁完整识别与记录功能）。收入完全依赖 App Store 的自然搜索流量，没有自有获客成本。

口径：MRR $2,869；累计收入 $62,352（RevenueCat API 验证）。

数据时点 ｜ 截至 2026-09-20（抓取日快照）｜口径：MRR

## 搜索关键词决定应用曝光
- 极其窄的单点需求，但那一刻的焦虑极强：被咬了不知道是什么、要不要去医院，这种「当下就要答案」的场景付费意愿远高于泛健康类工具
- 回答一个具体的恐惧，而不是提供一堆知识：产品不解释昆虫学，只回答「这是什么、我该怎么办」，把决策链路压到最短
- RevenueCat 侧验证的 MRR 约 $2,869、115 个活跃订阅、累计收入约 $62,352—— 一个人可以维护的体量，且 App Store 分发不需要自有获客
- App Store 的分发让这类长尾小工具可以长期挂在货架上收订阅，不需要持续投广告，因为搜索需求本身就在

## 短决策链路满足即时焦虑
- 找「低频但对个体极其重要」的搜索需求：用户一年只用两次，但每次都在焦虑中，这种需求做不成大平台，却撑得起一个一个人的订阅产品
- 识别类工具的关键不是准确率本身，是「在高不确定下怎么表达置信度」—— 给出可能性排序和就医建议，比强行给一个确定答案更让人接受
- 用完即走的工具要靠 App Store 自然搜索获客，所以标题和截图里的关键词比界面更重要
- 季节性产品要提前接受它的天花板：需求集中几个月，倍数自然低，这不是产品失败

## 自然搜索获客策略
这是「长尾单点工具」最真实的样本：体量不大、季节性明显、倍数偏低，但它证明了一个人可以用一个极窄的需求，换来一份不需要天天维护的收入。
