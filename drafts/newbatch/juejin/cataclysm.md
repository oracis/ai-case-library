# Cataclysm-DDA 的万物皆 JSON：一个 C++ 游戏如何靠数据驱动堆出十年内容

末日生存 Roguelike，代码量不算最大的那一档，但内容量惊人——上万种物品、上千种怪物、成百上千条合成配方。加内容的人大多不是 C++ 程序员，而是写 JSON 的玩家。

这份源码是「数据驱动」最彻底的样本之一：**引擎只提供机制，内容全部是外部数据**。值得看的不是它做了多少内容，而是它怎么让非程序员安全地加内容。

## 一、分层

- **引擎**（C++）：回合调度、地图、视野、战斗结算、UI
- **内容**（JSON）：物品、怪物、配方、地图生成、任务、变异
- **存档**（JSON）：整个游戏状态序列化
- **构建**：Make / CMake，依赖 SDL2（或 ncurses）、zlib

`data/json/` 目录下是几千个 JSON 文件，编译不参与——**改数值不用重新编译**，这是这套设计的最大收益。

## 二、JSON 里最有价值的设计：copy-from 继承

如果每个物品都从零写全字段，光是重复就能压垮维护。它的解法是原型继承：

```json
{
  "id": "knife_combat",
  "type": "TOOL",
  "copy-from": "knife_utility",
  "name": { "str": "combat knife" },
  "bashing": 6,
  "cutting": 14,
  "extend": { "flags": [ "SHARP" ] }
}
```

三个语义要分清，这是它这套系统真正的技术点：

- `copy-from`：以另一个条目为基类
- 普通字段：覆盖父级
- `extend` / `delete`：对数组/字典做增量修改，而不是整体替换

第三种是最容易被忽略、也最有用的。做配置系统时，如果只有「覆盖」没有「增量」，就会出现「我要在父级基础上加一个 flag，只能把父级整个数组抄一遍」——抄一遍的那天，就是配置漂移的开始。

## 三、行动点系统：回合制的时间模型

它不是「每回合每人动一次」，而是所有生物共享一条时间轴，每个动作消耗不同的「moves」：

```cpp
// 简化：每个生物有 speed，100 为基准
// 每 tick 累积 moves += speed，够 100 就能行动一次
// 攻击、走动、开箱消耗的 moves 不同
```

这套模型的工程价值：**不同速度、不同动作粒度可以混在一条时间轴上**，不需要给每种情况写特例。所有「回合制」产品（回合策略、卡牌、模拟经营）都能用这个范式。

坑也很明确：浮点累积会漂移。所以关键数值要用整数（int moves），否则长时间模拟后顺序会错乱。

## 四、地图与视野

- 地图是三维（多 z-level）的方块网格，每格记录地形、物品、生物
- 视野用视线追踪（line of sight）+ 光照缓存，只渲染可见部分
- 地图生成是「overmap + 局部地图」两级：先在世界地图上生成城市/道路，再在进入时生成具体地块

两级生成是沙盒游戏的标准解法：**世界级用低分辨率数据结构，进入时才生成高分辨率细节**。省内存，也让世界规模不受限。

## 五、存档是 JSON 的代价

整个存档序列化为 JSON，好处是**可读、可修、可迁移**——玩家能手工改档，开发者能写脚本迁移老档。

代价是：文件大、加载慢、存档膨胀。一个长期存档几十 MB 很常见。

这是「数据可读性」和「性能」的经典取舍。它的选择是宁可慢也要可读，因为一个能被人打开看的存档，等于给社区提供了修改器、迁移工具和 bug 复现能力。

## 六、读代码的入口

1. `src/item.cpp` —— 物品基类与能力挂载，看机制如何与 JSON 字段对应
2. `src/mapgen.cpp` —— 地图生成，看两级生成怎么衔接
3. `data/json/items/` —— 挑一个物品沿 `copy-from` 链往上读，理解继承体系
4. `src/savegame_json.cpp` —— 存档序列化，学「可读存档」怎么设计

## 七、门槛

- 编译依赖 SDL2、SDL2_image、SDL2_ttf、ncurses、zlib，Windows 用 MSYS2 最顺
- JSON 加载器对格式极敏感，一个逗号错了报错信息很难定位
- C++ 代码风格偏老，很多函数上千行

## 八、能搬走的设计

- **配置继承三件套**（copy-from / 覆盖 / extend-delete），少一个都会在内容量上来后崩
- **整数时间轴**，别用浮点推进模拟
- **两级数据结构**（粗世界 + 细局部），是沙盒游戏的通用解法
- **存档可读**，是给社区留了扩展口，也是给自己留了调试口
