# 用 AI 识别虫咬类型：一个 iOS 单点工具的收入结构

## 低频焦虑场景的搜索需求定位
拍照识别虫咬类型的 iOS 应用：给出可能的虫种、置信度与护理建议，并记录咬痕随时间的变化。免费下载，核心功能靠内购订阅解锁。

公开口径：MRR $2,869、累计收入 $62,352、115 个活跃订阅（RevenueCat 支付侧 API 验证）。
数据时点 ｜ 截至 2026-09-20 抓取日快照 ｜ 口径：MRR 为当月经常性收入，$62,352 为累计收入，不可年化。

## 高不确定下的置信度表达策略
免费下载 + 内购订阅解锁完整识别与记录功能。识别类工具的关键不是准确率本身，而是在高不确定下怎么表达置信度：给出可能性排序和就医建议，比强行给一个确定答案更容易被接受。产品也不解释昆虫学，只回答「这是什么、我该怎么办」，把决策链路压到最短。

## App Store 自然搜索的关键词布局
- 找「低频但对个体极其重要」的搜索需求：用户一年只用两次，但每次都带着焦虑，这种需求做不成大平台，却撑得起一个人的订阅产品
- 用完即走的工具靠 App Store 自然搜索获客，标题和截图里的关键词比界面更重要
- 需求有明显的季节性，集中在温暖月份；做规模预估时要把这个前提写进去
- 单点工具的维护成本要压到一个人能承担，功能边界比功能数量更值得先定

## 把决策链路压到最短的恐惧回应
- 极其窄的单点需求，但那一刻的焦虑极强：被咬了不知道是什么、要不要去医院
- 回答一个具体的恐惧，而不是提供一堆知识，是这类工具能收到订阅费的主要原因
- 按 2026-09-20 快照，MRR 约 $2,869、115 个活跃订阅、累计收入约 $62,352——一个人可维护的体量，且 App Store 分发不需要自有获客成本

一句话总结：体量不大、季节性明显，但它证明一个人可以用一个极窄的需求，换来一份不需要天天维护的收入。
