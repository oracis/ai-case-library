# AI 一键生成演示文稿：借编辑器杠杆省成本

## 它做什么

把一个主题或一段文档直接变成演示文稿：AI 生成大纲和每页文案，再通过 Google Slides / PowerPoint 集成导出成可直接编辑的 PPT。交付面用的是成熟编辑器，自己这一侧只做生成。

## 数据快照：截至 2026-09-20 的抓取日

MRR 11,332 美元；累计收入 714,537 美元；825 个活跃订阅。收入数字由 TrustMRR 页面注明以 Stripe API key 验证。

口径要单独说清楚：714,537 美元是 2023-01 上线至今的累计收入，不是 ARR，也不是 MRR，不能年化；经常性口径只有 MRR 这一项。另有两条容易混的旧说法：来源页原文里既没有「收入 9.1K」，也没有「要价 500K / 倍数 4.6x」（FOR SALE 区块列的是别的项目），这些都不作为事实使用。

## 省自研 UI 成本，把工程量投到生成质量

月订阅，按生成额度和导出次数分档，对标的是用户原本花在模板、外包或加班上的时间成本。接 Google Slides 和 PowerPoint 意味着不用自研编辑器，产品的重心全压在生成质量这一件事上。

## 为什么这个位置能撑住订阅

- 做「别人的编辑器 + 你的生成」：把自研 UI 的工程量省下来，这是一个人能撑住这类产品的关键
- 挑高频低价值场景：做 PPT 是每个职场人反复要做的事，但很少有人愿意为它专门请人设计
- 上线时机的价值大于功能完整度；同一类产品晚两年做，获客难度会明显不同
- 单点功能也能撑起一份业务，前提是它的使用频次足够高

## 可复用的判断

卡在「高频但不值得认真做」的位置上，需求落差由一键出稿接住；借别人的编辑器交付，自己只把生成这一件事做到能用。不追求做平台，追求做那个被反复调用的开关。
