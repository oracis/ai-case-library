# 把卖货页、会员和付费社群收进一个链接的创作者收银台

## 创作者一站式卖货页搭建
给创作者做「一站式卖货页 + 会员订阅」的平台：把商品、预约、付费社群、订阅内容塞进一个可分享的链接里，创作者不需要自己的网站，也不需要接支付。

公开口径：MRR $3,569,654；累计收入 $76,627,685（Stripe 直连验证）。

数据时点 ｜ 截至 2026-09-20（抓取日快照）｜口径：MRR

## 会员订阅与付费社群整合
交易抽成 + 订阅套餐。创作者在平台上卖货、卖会员，平台按交易额抽成；收入随平台整体 GMV 增长，而不是随平台自己的销售增长。

## 支付网关直读收入证据链
- 别做「更好的工具」，做「服务对象的收银台」—— 收入的增长逻辑从「卖更多份」变成「客户卖得更多」
- 入门路径要短到「打开链接就能收钱」：每多一步注册/配置，流失掉的人都是平台的长期抽成
- 注意体量带来的口径风险：月收入到千万级这类数字，必须保留「由支付网关直读」的证据链，否则读者无法判断真假
- 先服务一个你能理解其收入结构的人群（本例是创作者），再谈平台化

## 创作者经济收银台抽成模式
- 收入已经被支付商 API 直读：MRR 约 $3,569,654、累计收入约 $7,662 万；TrustMRR 页面自标 Ranked #3，这类数字没法靠话术造出来
- 它站在「创作者经济」的收银台上：创作者每卖出一单它就抽一笔，平台的收入直接等于整个创作者群体的交易额乘上一个比例，不用自己去获客
- 「一个链接卖所有东西」把门槛压到极低 —— 创作者不需要域名、不需要建站、不需要懂支付对接，打开就能收钱，这正是它相比 Shopify 类工具的差距所在
- 创作者最怕的是「收入渠道分散」，它把这些渠道收进一个后台，迁移成本随粉丝增长而上升

一句话总结：它证明创作者经济的收银台是一门比创作本身大得多的生意 —— 但这些数字必须带着支付侧证据看，因为它们已经大到「听起来不像真的」的量级。

出处：TrustMRR – Stan 收入页、stan.store 官网（2026-09-20 快照）。
