# 今天拆解一个 bootstrapped 六年的 SaaS：用户反馈投票板 + 公开路线图

> 平台：bilibili ｜ 案例：Upvoty（upvoty）｜ 状态：待推送（本地草稿，未真实发布）

大家好，今天我们要来拆解一个 Bootstrapped 六年的 SaaS 项目——Upvoty。它通过用户反馈投票板和公开路线图，实现了 $40K+ 的月收入（MRR）。听起来是不是很厉害？让我们一起来看看它是怎么做到的。

🌟 Upvoty 是做什么的？
Upvoty 是一个客户反馈管理工具，它可以帮助产品团队收集用户反馈、制定公开路线图，并通过 AI 辅助决策下一步应该做什么。简单来说，它就像是一个连接用户和产品团队的桥梁，把散落在工单、邮件、表格里的反馈变成可执行的优先级。

🚀 怎么赚钱？
Upvoty 采用订阅制 SaaS 模式，低价档切入市场，目前有 2,000 多个团队在使用。它的获客方式主要依靠内容营销和 SEO，比如「Alternatives to」系列、Product Hunt 发布以及集成生态带来的留存。据创始人透露，他们的获客成本低于 $500/月。

🎯 为什么能成 / 方法论？
顺序是反着来的：先用一天搭个落地页，数周拿到 200+ 注册才动手写产品，而且上线即收费、不设免费档。发布之后靠两条腿走路——写「Alternatives to …」系列截流竞品的不满用户，再按用户点名接 GitHub / Slack / Jira 集成，集成接完就变成了留存。指标用 Baremetrics 管，重留存轻虚荣指标，获客成本压在 $500/月以内。
1. 落地页验证：创始人通过搭建一个简单的落地页，验证了产品的市场需求。
2. 内容营销与 SEO：通过撰写高质量的内容，优化搜索引擎排名，吸引潜在客户。
3. 产品集成：与其他工具集成，提高产品的可用性和用户粘性。

📈 可复制性
Upvoty 的成功具有一定的可复制性，以下是一些可借鉴的点：
