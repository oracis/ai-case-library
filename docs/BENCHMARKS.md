## 1. 退出估值参照：TrustMRR 市场成交均价 1.9x

- 统计口径：过去 365 天 148 笔成交，平均 **1.9x** 倍数，平均 **23 天**成交周期。
- 用途：任何产品自估退出价时，心理价位应先对标 1.9x 年化收入。
  实际自估值常高出市场价 5 倍以上。
- 建议落成 UI 里的「估值参照器」：填入年化收入 → 给出1.9x 对应价区间。

## 2. 收入口径六项自检（每篇案例的必填校验）

| # | 口径 | 陷阱 |
|---|---|---|
| 1 | ARR | 年化经常性收入，**不等于**已到账现金 |
| 2 | run-rate | 按某月/某季乘出来的估计值，**不等于**已发生 |
| 3 | 累计收入 lifetime | ≠ 年收入（Chatbase / ShipFast 都栽在这） |
| 4 | 平台流水 GMV | 不是收入（Nitra / Genius AI 的数十亿是流水） |
| 5 | 毛利率 vs 净利 | 两者差别极大，不可互换 |
| 6 | 「年化处理量」 | 是业务量，不是收入 |

建议做成详情页常驻提示。

## 3. TrustMRR 榜单口径审计（为什么必须抓公司页）

同一个榜单上「MRR」与「All time」两种口径混用。已确认的对照点：

- ShipFast 的 `$1.27M` 是 **all-time**（TrustMRR 公司页明写 All-time revenue）
- Chatbase 的 `$863,632` 是 **MRR**（另一独立文章引用其「MRR」）

⇒ 依赖榜单快照做判断有风险，应自己抓公司详情页。

## 4. 小团队收入基准线

- 样本：Lancer.app（$20K MRR / 95 订阅）、StoryShort.ai（$20K）、CheckVibe（$3.4K / 6 周）
- 2 人团队常见区间：**$3K – $20K MRR**
- 用途：横向排开同规模样本，比看单个爆款案例有用得多（爆款是小概率事件）。
