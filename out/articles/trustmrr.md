## 它是干什么的

创始人用只读 API key 连 Stripe / LemonSqueezy / Paddle 等，收入由支付数据自动验证后公开展示，不看截图。买家看到真实 MRR、订阅数、流失、增长，直接联系卖家谈收购。


## 钱从哪来

成交抽成 4–6% + 一次性上架费 $29 起 + 可选曝光加购（$19 链接、$79 AI 可见度、$399 起侧栏赞助）。另有 $199/年 的 Startup Signals 数据库订阅。

## 它为什么能成

- 买家愿意为「不用验证」付钱——200,000 月访问量是被「验证」这个词拉来的。
- 卖家免费上榜，需求侧（买家）和供给侧（卖家）同时起步，双边市场冷启动靠上架费而非抽成，不依赖成交才有收入。
- 平均 23 天完成收购、定价合理的项目 48 小时内收 3 个报价——速度快本身就是差异化。
- 创始人 Marc Lou 本身就是社区头部 KOL（38 万 X 粉丝），冷启动不靠广告。

## 能搬走的部分

- 如果你所在的圈子存在普遍的信任问题，把「验证」做成产品或榜单——信任本身就是可售卖的稀缺资源。
- 双边市场可以从供给侧的「一次性上架费」起步，不必等成交抽成。
- 创始人自己的流量是最好的冷启动。如果还没流量，先去攒流量，而不是先做产品。
