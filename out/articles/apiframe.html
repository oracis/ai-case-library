Apiframe：MRR $36,843，TrustMRR 实时核对

今天拆一个海外小生意，收入数字都是公开可核验的。
AI 模型层的「卖水人」：不赌哪个模型赢，只收过路费——模型越百花齐放，网关越值钱。
它干什么、钱从哪来、做到多大、值不值得抄，下面一篇讲完。

它是干什么的

Apiframe 做 AI 模型 API 网关：开发者用一套 API 调用多家模型（图像/视频生成等），按 credits 用量计费，付费计划 $39/月起（年付 $19/月起价）。新加坡团队（创始人 Renaud，2021 年 8 月成立），目前 MRR $36,843、881 个订阅、近 30 天收入 $48,112、累计 $494,170。

钱从哪来

Usage-based credits：按调用量扣费，速率与价格随模型不同。付费门槛 $39/月，对个人开发者友好；用量上来后自然升级——收入随客户业务增长而增长，这是 API 网关类产品最健康的收入结构。

它为什么能成

客户痛点是「接一家模型写一套代码」，Apiframe 把 N 个 API 的集成成本压成 1 个——这是典型的开发者工具价值主张。

按量计费让收入天花板跟着客户走：客户业务长大，credits 消耗自动上升，无需涨价、无需换套餐，没有订阅制那种「到顶就流失」。

五年积累（2021 年成立）吃到了 AI 应用爆发的完整周期——早入场意味着模型覆盖列表本身就是壁垒。

新加坡团队服务全球开发者：基础设施类产品没有本土市场限制，支付网关验证的收入就是全球开发者的合力。

能搬走的部分

在快速碎片化的技术层做「统一接口」，赌的是分化持续，不是某一家赢。

按量计费优于订阅：收入随客户成长自动扩张，且没有套餐天花板。

开发者工具的冷启动靠文档与示例代码，不靠销售。

覆盖列表是复利型壁垒：每多接一个模型，迁移成本就高一分。
