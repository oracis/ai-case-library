> 「$424,368 是 GojiberryAI 的累计收入」

> 我去核了一遍：$424,368 是 MRR（月度经常性收入）；累计收入是 $1,801,629，TrustMRR 上是两个分列字段


## 它是干什么的

面向 B2B 团队的 AI GTM 平台：定义理想客户画像（ICP）→ 监控职业信号（谁在换工作、融资、招人）→ 给线索打分并补全资料 → 自动跑 LinkedIn / 邮件触达。它卖的不是联系方式，是「时机」。


## 钱从哪来

月度订阅。Pro 套餐 $99/月（含 2 个 signal / outreach agent、2 个 LinkedIn 发送号），每多一个 agent / ICP / 发送号 $59/月；再往上是定制团队计划和年付。agent、席位、ICP、联系量四个维度都能随客户变大加钱——收入不靠涨价，靠客户自己变重。

## 它为什么能成

- 产品还没写就已经有人付钱：一份 PPT 加人工交付，把「帮你在对手之前找到最热的线索」卖到逼近 $10K MRR，每天能约 5–6 个 demo。他们工程化的是被验证过的工作流，不是假想的功能清单。
- 卖的是决策时机而不是名单：换工作、融资、招人都是可观察的采购信号，转化远好于泛名单，而且可每天刷新，天然适合订阅。
- 用自己的产品给自己拉客户：每天从真实回复里回收信号质量的反馈，反过来优化模型，形成数据—增长飞轮；Reddit 一条帖子带来约 1100–1200 万次浏览、4 万网站访客。
- 渠道是分层叠加而不是单点爆发：outbound → Reddit → LinkedIn 内容 → SEO / YouTube → newsletter / 联盟 → 付费广告 / 招销售，一层比一层贵，一层一层往上加。

## 能搬走的部分

- 在写第一行产品代码前，先用人工服务证明「有人愿意为这个结果付钱」——卖 outcome，不卖 feature。
- 选窄 ICP + 一组可观察事件；把「信号」当成带衰减的假设来建模，别当成事实直接群发。
- 渠道分层、由便宜到贵依次加码；最好让自己的产品成为自己的获客工具。

整套动作长在 LinkedIn / Reddit 的开放数据和自动外发上。国内两边都缺：既没有等价的职业信号源（LinkedIn 职场版 2023 年就关停了），《个人信息保护法》又把「抓取 + 群发」直接定性为红线——与 meerkats-ai 撞的是同一堵墙。真要落地得把信号源换成企查查 / 脉脉，触达换成企业微信，等于重做一遍产品；而那一格还站着探迹、销售易、纷享销客。唯一不看国界的是它的方法论：先用人工交付证明有人为结果付钱，再把它写成软件。

**卡点**：自动化触达合规
