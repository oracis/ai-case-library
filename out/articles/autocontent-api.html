AutoContent API：MRR $17,036，TrustMRR 实时核对

今天拆一个海外小生意，收入数字都是公开可核验的。
API 化是这个时代最快的变现路径：同样的 AI 能力，做成 App 要获客，做成 API 是客户带着需求上门。
它干什么、钱从哪来、做到多大、值不值得抄，下面一篇讲完。

它是干什么的

AutoContent API 提供多格式内容生成 API：开发者把文案/营销内容生成能力集成进自己的产品。西班牙团队（创始人 Miguel Pieras，2024 年 10 月成立），目前 MRR $17,036、145 个订阅、近 30 天收入 $16,764、累计 $239,061。

钱从哪来

三档订阅：Amateur $33/月、Professional $66/月、Business $124/月。145 个订阅 × $17K MRR ≈ $118 均价，说明客户集中在 Pro/Business 档——集成 API 的都是真在跑业务的人。

它到底做到多大

官方口径：MRR $17,036，TrustMRR 实时核对

备注：实测口径：MRR $17,036（TrustMRR 从支付网关 API 直读，2026-07-09 同步，Stripe (API key)）。近 30 天收入 $16,764、累计 $239,061、付费订阅 145 户。最近完整月环比 +2.3%（已剔除当月残月）。近 30 天 MRR 增速 +0.4%。⚠ 同期收入增速为 +6.8%，与 MRR 增速不一致（一次性入账/退款等会造成背离）—— 讲增长必须用 MRR 口径。⚠ 历史峰值 $16,908 → 最近完整月 $16,908，留存 100%。挂牌 $1,200,000、倍数 6.00x（要价不等于收入）。⚠ 队列缓存值是 2026-10-14 采集时的快照（当时 $17,036），与上述实测不同；本条以实测为准。

它为什么能成

客户是开发者而非终端用户：没有获客成本、没有客服压力，文档就是销售，集成成功就是留存。

三档定价精准对应客户体量：业余项目 $33、正式产品 $66、商业部署 $124——按用量感知定价，升级路径天然。

上线两年 $23.9 万累计：API 生意一旦集成进客户产品就很难被替换，收入随客户业务自然增长。

「多格式」是差异化：不局限单一文案类型，客户一个 API 接走全部内容需求，切换成本堆高。

能搬走的部分

有能力先做 API 版：开发者客户比 C 端用户好服务十倍。

按客户体量分三档，让升级成为成长的必然而非推销的结果。

文档与示例代码的质量就是转化率，别省这份精力。

集成即锁定：让客户的代码里到处都是你的调用。

**卡点**：生成式 AI 备案 + 大厂 API 价格战
