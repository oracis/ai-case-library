游戏厅：2048

2048 是一款风靡全球的数字合并解谜小游戏，此条目为其开源网页实现（克隆版），源自原作《1024》的玩法…

开源游戏拆解 · 它用的是什么技术

它是什么

游戏在 4×4 的方格上进行，玩家滑动方块让相同数字合并翻倍，界面简洁、规则极简，却有着令人上瘾的深度，曾引发全球性刷屏热潮，并在各平台上被大量移植和改编。开源代码托管在 GitHub，可本地运行或部署成网页版。

怎么玩

游戏目标是在棋盘上合成出 2048 方块，若棋盘填满且无法合并则游戏结束。每次操作（上下左右滑动）会移动所有方块并在随机空位生成一个新的 2 或 4，相同数字相撞即合并。新手的关键提示：固定一个大数贴在角落，只在两个方向上滑动，让方块保持有序的递增排列，千万不要把大数从角落里挪开。源码可自行运行或部署。

顺手看看代码

代码按功能分目录，style 存 CSS，js 存 JavaScript 逻辑，meta 存元数据。js 文件按依赖顺序排列，形成自底向上的调用链，从底层输入处理到顶层游戏管理。这种组织方式符合游戏开发中各模块解耦的需求，便于维护和扩展。

从 js/application.js 开始读，它是顶层入口，负责初始化游戏流程。因为它整合了所有核心模块，如输入管理、界面渲染和游戏逻辑，是理解整体架构的起点。

· GameManager.prototype.setup 和 addStartTiles 展示了游戏初始化的抽象设计，将随机生成和状态初始化分离处理

· HTMLActuator.prototype.applyClasses 和 normalizePosition 体现了 UI 更新的组织方式，通过类名组合动态调整样式

它用什么技术做的

原版是一位意大利开发者用 JavaScript 写的网页小游戏：4×4 棋盘是 DOM 元素，滑动动画交给 CSS transition，真正有分量的只有「合并同类项 + 计分 + 判负」这几百行逻辑。它常被当作「读懂一个完整游戏循环」的样本——状态、输入、动画、重开，一样不缺。
