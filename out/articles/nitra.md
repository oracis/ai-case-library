> 「Nitra 有 7000 多家诊所在用」

> 我去核了一遍：公司官方披露为 700+ 家诊所、2,500+ 名医生。2026 年的目标是突破 3,000 家。「7000 家」在公开材料中找不到依据。


## 它是干什么的

医生要自己排病人、验保险资格、订药、付供应商、对账、管员工。Nitra 把这些塞进一个后台，用 AI agent 自动化。


## 钱从哪来

先靠一张 Visa 企业卡切进诊所的资金流，再从财务自动化扩到采购、库存、病人管理。软件订阅 + 支付与采购流水。


## 它到底做到多大

| 维度 | 内容 |
| --- | --- |
| 官方口径 | $33M ARR（2025）→ 目标 $150M（2026） |
| 年化收入 | $33M |
| 客户 | 700+ 家诊所、2,500+ 名医生 |
| 团队 | 50 人（2025）→ 计划 200+（2026 年底） |
| 融资 | 股权 $90M + 债权/仓单合计 $205M（2026-03 公布） |
| 增长 | 2025 年收入增长 740%+，从 $4M 到 $33M 年化 |
| 备注 | 2026 年目标：3,000+ 家诊所、年化收入 $150M、年化处理流水 $40 亿。 |

**还有一条被抄错的流传的说法**：「Nitra 一年赚接近 2 亿美金」（与 Genius AI 的数据被混用）

**实际情况**：Nitra 2025 年化收入为 $33M，2026 年目标是 $150M。接近 $200M ARR 的是 Genius AI（GlossGenius），不是 Nitra。


## 它为什么能成

- 美国医疗年支出约 $5.9 万亿，其中约 25% 花在行政成本上——这是一个纯粹的浪费池，谁减少它谁分钱。
- 独立诊所正在被挤压：小独立执业医生占比从 2012 年的 60.1% 跌到 2024 年的 42.2%，他们急需运营工具活下去。
- 切入点是金融而非软件：先用企业卡、账单支付建立资金通道，再往上叠 AI 模块，客户粘性远超纯 SaaS。
- 创始团队上一个公司 FiscalNote 做了 5,000+ 客户、900 人，懂怎么在受监管行业里做规模化。

## 能搬走的部分

- 找「行业总支出 × 行政成本占比」双高的领域——这个乘法结果就是你可拿走的市场。
- 如果纯软件卖不进这个行业，就从金融切：银行卡、账期、垫资往往比 SaaS 更容易进门。
- 按模块递进叠加，不要一次上全家桶；每加一个模块都要真能省下一块人工。

## 能不能搬回国内

**中国移植分：49.3 / 100**

| 维度 | 内容 |
| --- | --- |
| 付费意愿 | 4/5 |
| 支付可达 | 4/5 |
| 合规空间 | 1/5 |
| 获客迁移 | 3/5 |
| 改造成本 | 1/5 |
| 竞争空位 | 1/5 |

医疗数据在国内是强监管（等保、HIS 资质、数据不出院），且卫宁健康这类厂商已深耕二十年。移植的难度不在产品，在牌照。

**卡点**：医疗合规


## 一个人能不能做

**个人可做性：30.3 / 100**

| 维度 | 内容 |
| --- | --- |
| 造得出来 | 2/5 |
| 单人交付 | 1/5 |
| 够得着客户 | 1/5 |
| 启动轻 | 1/5 |
| 窗口还开着 | 3/5 |

医疗软件要过资质、数据不出院、HIS 对接，合规和技术支持都必须有团队和法人主体。


## 我的判断

又是一条脏活。但请注意：很多中文转述把它的客户数写成了「7000 多家」，公开披露是 700 多家——差了一个数量级。

**结论**：别碰（综合 34.1 分）
