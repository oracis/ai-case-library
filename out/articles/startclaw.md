> 今天拆一个海外小生意，收入数字都是公开可核验的。

> 和 Coral 几乎同题，差别在获客：它靠 X + Discord 支持频道 + 早期推荐循环，而不是线下 workshop。

> 它干什么、钱从哪来、做到多大、值不值得抄，下面一篇讲完。


## 它是干什么的

开箱即用的 agent 托管环境，省掉自己准备服务器和环境变量的步骤。


## 钱从哪来

月订阅，$1,619 MRR / 21 个活跃订阅，客单价约 $77/月。


## 它到底做到多大

| 维度 | 内容 |
| --- | --- |
| 官方口径 | $1,619 MRR |
| 客户 | 21 个活跃订阅；发布时 700 注册 / 50 付费 |
| 团队 | 未披露 |
| 融资 | 未披露 |
| 增长 | 2026-02 发布，TrustMRR 于 2026-08-31 显示 $1,619 MRR |
| 备注 | 700 注册转 50 付费 ≈ 7.1% 注册转付费率，可作为同类产品的初始基准。 |


## 它为什么能成

- 消除的正是最劝退的那一步——「先装环境」。这一步劝退的人比不感兴趣的人多得多。
- onboarding 就是护城河：注册到跑起来的时间越短，转化越高、流失越低。
- 用 Discord 做支持同时做社区，早期推荐循环免费。
- 和 Coral 同题说明这个需求是真实的——不是某个人的孤例。

## 能搬走的部分

- 把「首次成功」的时间压到最短。这是自助产品唯一真正重要的指标。
- 用 Discord / 微信群把支持和社区合并，用户提问本身就是内容。
- 发布时把注册数与付费数一起公开，7% 左右的注册转付费可以当作自己的第一版基准线。
