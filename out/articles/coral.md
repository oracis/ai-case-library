> 今天拆一个海外小生意，收入数字都是公开可核验的。

> 底层 agent 已经开源、人人可下载的年代，「帮你把它跑起来」本身就是产品。

> 它干什么、钱从哪来、做到多大、值不值得抄，下面一篇讲完。


## 它是干什么的

把开源 agent 框架的部署、托管、权限凭据、集成、模板打包好，让不懂运维的人也能用上。


## 钱从哪来

月订阅。卖的不是模型能力（那个免费），而是配置、托管、凭据管理和模板。

## 它为什么能成

- 模型和 agent 框架免费之后，价值迁移到了「最后一公里的折磨」上——权限、环境、集成、稳定性。
- 「配置即产品」是被反复验证的模式：WordPress 免费，但托管 WordPress 的公司赚了几十亿。
- 获客靠创始人自己办 workshop 而不是投广告，成本低且转化率高。
- 护城河在可靠性和权限管理，不在 prompt。

## 能搬走的部分

- 当底层能力变得免费且易得时，去做「让它真的能在生产环境跑起来」这一层。
- 用 workshop / 直播 / 陪跑替代广告。对开发者产品，一场实操比一万次曝光有用。
- 定价要体现「省下的运维时间」，不要按 API 调用量转卖。
