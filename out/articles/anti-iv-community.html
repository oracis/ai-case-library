这些分发买不到，只能攒

前三篇讲的三类门槛——账单、人头、苦力——都有一个共同点：理论上钱能换时间。这一篇讲第四类，它换不了。
这三条的护城河都是「一群人自愿聚在你这里」：2500 万粉丝的创作者网络、20.4 万 GitHub 星、800 万月活。这类资产既不能买，也不能加速，只能攒。而且它不随产品转移——你做出一个更好的产品，这些粉丝和星不会跟过来。
它们也都不是失败案例。正相反，这一类里有一条是 33 条中最容易被误读成「你也能」的：零融资、6 个月、¥6,720万 ARR。这一篇要拆的就是这个「也」字。

三条摆出来

Doomers：病毒式分发即服务 · 2500 万粉丝创作者网络 · 6 个月 ARR ¥6,720万 · 零融资

n8n：工作流自动化 · 20.4 万 GitHub 星 · 23 万活跃用户 · ARR 超 ¥2.69亿 · 估值 ¥168亿

OpenCode：终端编程工具 · 一年 800 万月活 · GitHub 最受欢迎 · 预计年收入 ¥1.68亿

Doomers —— 「零融资」是最容易骗人的那三个字

左手握 2500 万粉丝的创作者网络，右手接 AI 公司的发布需求，6 个月做到 ¥6,720万 ARR，零融资。

这三个要素单看都很有号召力：没融资、起步半年、收入到了几千万。把它们读成「一个人也能做」，是最自然的误读，也是最贵的误读。

把资产那一层补上就清楚了：它真正的资产是 2500 万粉丝的创作者网络，这是十年攒的关系资产。零融资是真的，但它零融资的原因不是「不需要钱」，是它已经有一个别人拿钱也买不到的东西。

再看交付：「病毒式分发即服务」的交付物是排期与创作者协调，人工密度很高——它更像一家媒介代理公司，而不是一家软件公司。而客户是 AI 公司的发布预算，属于甲方市场，议价权不在它手上。

所以这条的正确读法不是「零融资的神话」，而是「关系资产算不算护城河」：算，但它有两条硬限制——不能继承（换个人这些关系就散了），不能加速（十年就是十年）。

n8n —— open-core 只在「必须合规」时才开始赚钱

把 AI 和自动化画在同一张画布上的工作流平台：20.4 万 GitHub 星、23 万活跃用户、ARR 超 ¥2.69亿、估值 ¥168亿。

它同时占了两类门槛：400+ 个第三方系统的连接器是上一篇讲的苦力，而 20 万星是这一篇讲的社区。把两者分开看，能看清 open-core 的赚钱机制。

社区版免费，付费来自企业合规与托管。这句话的意思是：开源的那些年里它并没有在赚钱，付费转化只在「企业必须合规」这个时刻才发生。

而这个时刻要等两件事同时成立：一是用过的人多到进了公司，二是公司大到需要合规。前者是社区，后者是时间。20 万星的积累跨了七个版本周期，同期同类产品大多已经停更——这句话既是它的成绩，也说明了这条路的成功率。

给一个人用的判据：open-core 不是一种变现方式，是一种先付出七年再谈变现的顺序。如果你需要收入来维持开发，这个顺序是反的。

还得补一句幸存者偏差：「20 万星」这句话里藏着一批没能写下同样句子的项目。同期做同类产品的，大多已经停更——它们不是做得差，是没能在变现时刻到来之前把社区撑到那么大。所以读到这类案例时，正确的问法不是「我能不能也开源」，而是「我能不能在没有收入的七年里不断更」。

OpenCode —— 贡献者只在「你已经是标准」之后才来

不做模型也不绑 IDE，卡在中间做「谁的模型都能接」的终端编程工具，一年做到 800 万月活、GitHub 最受欢迎。

它的位置很好，但赚钱方式暴露了一个结构问题：核心工具开源免费，收入来自按 token 收费的 Zen 网关——等于自己开了一家模型分销。

也就是说，它用开源拿到了分发，再用分发去做中间商。这跟 OpenRouter 那类生意撞在了同一条路上，要面对同样的冷启动问题，只不过它用 800 万月活把这个冷启动跳过去了。

代价是运维与社区治理成本，与收入不成比例。800 万月活的开源项目，光是处理 issue、审核 PR、维护兼容性就是全职工作量，而这笔支出不从 token 分销里自然长出来。

还有一层更根本的：开源编程工具的护城河是贡献者数量，而贡献者只在「你已经是标准」之后才来。这是一个典型的先有鸡还是先有蛋——它已经过了那个点，但后来者要过的正是同一个点。

顺便点一句同赛道：Claude Code / Cursor / Codex，全部有大厂预算在烧。这个位置不缺竞争者，缺的是第二次机会。

最后记一笔它自己的数字：卡片上是 ¥1.68亿，而页面原文写的是「预计年收入」，口径段自己也注明「为『预计』而非审计数字」——标签写的却是「月收入」。也就是说这条同时占了两个错：年当成月，以及把预计当成事实。

攒的三种形态

三条读完，社区资产在这里以三种形态出现：

关系资产：Doomers —— 2500 万粉丝的创作者网络，不能继承、不能加速

标准资产：n8n —— 20.4 万星，跨七个版本周期，付费只在合规时刻发生

默认资产：OpenCode —— 800 万月活，贡献者只在「已经是标准」之后才来

共同点只有一句：它们都是别人给的，不是自己做的。你可以做出更好的产品，但你没法命令粉丝关注你、给项目点星、把你设成默认。

社区资产和上一篇的信任链有什么不同

这两类都靠「别人对你的态度」，但性质差别很大，值得分开记。

信任链是给少数人的。Applied Compute 只需要让几十家企业相信「他们是 OpenAI 原班人马」，这个信任可以在一次会议里建立。

社区资产是给多数人的。20 万星需要二十万次独立判断，每一次都很轻，但你必须挨个拿到。所以它慢，但它一旦成型，不依赖任何一个人的记忆——这是它比信任链更硬的地方。

反过来说，信任链有个社区没有的优点：它可以在创业第一天就生效。Applied Compute 出 stealth 就有客户，而 OpenCode 得先熬一年才有 800 万月活。所以这两类的取舍是：信任链快但薄（换个人就散），社区慢但厚（换个人还在）。

「零融资」这类标签为什么特别容易骗人

这一篇三条里有两条带着「没融资 / 免费」这类标签，值得单独讲，因为它们是传播力最强、也最容易误导的一类词。

「零融资」描述的是资金来源，不是门槛高低。Doomers 零融资，是因为它有 2500 万粉丝的创作者网络——一个别人拿融资也买不到的资产。把「没花投资人的钱」读成「没花本钱」，就把最贵的那种本钱漏掉了。

同理，「开源免费」描述的是定价，不是成本。n8n 的社区版免费，它付出的代价是七年。看一门生意的门槛，永远看它投入了什么，不要看它收了多少。

怎么识别

一问：这个分发能不能用钱买到？买量能买到下载，买不到 20 万星；投放能买到曝光，买不到「默认」。答案是「不能」的，就是这一类。

二问：它攒了多久？n8n 跨七个版本周期，Doomers 的创作者网络是十年。把这个数字减去你打算投入的时间，剩下的就是差距。

三问：换个人这些资产还在吗？不在，就说明它挂在人身上而不是产品上——这既是护城河，也是它无法被收购、无法继承的原因。

不是失败案例

Doomers 零融资做到 ¥6,720万 ARR；n8n 估值 ¥168亿、23 万活跃用户；OpenCode 一年 800 万月活。

这三条都是成功的。「买不到」说的是获取方式，不是说它不值钱。恰恰相反——正因为买不到，它们才值钱。

落点

这一篇对个人不是全然的坏消息，因为社区资产是唯一一种「没钱也能攒」的护城河。但攒法有讲究。

一、把「攒」当成主线，不是副产品。如果你打算先做产品再顺手运营社区，顺序就错了。n8n 的顺序是先有社区后有收入。

二、选一个能积累的单位。星、粉丝、月活都能积累；曝光、热搜、推荐位不能。判断标准：今天的投入在三年后还剩下多少。

三、别在需要「合规时刻」才变现的品类里熬。open-core 的付费来自企业合规，这意味着个人用户再多也不产生收入。如果你想早点收到钱，就得选一个个人愿意自掏腰包的场景。
