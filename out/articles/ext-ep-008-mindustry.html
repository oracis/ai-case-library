游戏厅：Mindustry

Mindustry 是一款开源的沙盒塔防与资源管理游戏，融合了塔防、即时战略和工厂自动化玩法。

它是什么

玩家在一张张地图上开采铜、煤等资源，建造传送带网络把物料输送给各类炮塔，抵御一波波敌人的进攻，同时还可以生产单位主动出击摧毁敌方核心。游戏使用 Java 编写，支持 Windows、Linux、Android 等多平台，拥有单人战役、生存模式和多人联机，凭借独特的'物流即防御'设计广受好评。

怎么玩

核心玩法是：用钻头开采资源，用传送带把物料运到炮塔供其开火，抵挡一波波敌人，并保护自己的核心不被摧毁。进攻方面，可以在工厂中生产地面与空中单位，编队攻打敌方核心。战役地图间还有科技树解锁新建筑。新手提示：先看懂每种炮塔需要什么弹药——传送带供弹是本作的灵魂，前期确保铜和煤的稳定供应比多造炮塔更重要。

顺手看看代码

代码组织围绕 annotations 和 android 两大目录展开。annotations 目录下的 src/main/java 结构清晰，按功能划分如 entity、remote、impl 等子目录，每个子目录包含处理特定任务的 Java 类。android 目录则专注于移动端适配，包含 AndroidLauncher 作为入口。这种结构体现了模块化和平台隔离的设计思路，annotations 目录负责核心逻辑和注解处理，android 目录处理平台特定代码。

从 annotations/src/main/java/mindustry/annotations/entity/EntityProcess.java 开始读，因为它直接体现了注解处理的核心逻辑。该文件定义了如何解析和处理实体相关的注解，包含 getImports、EntityDefinition 等关键符号，是理解游戏数据结构和注解应用的基础。

· getImports 和 EntityDefinition 的设计展示了如何通过注解动态生成游戏实体类，体现了反射与代码生成的结合。

· makeWriter 和 makeReader 的实现体现了远程调用模块的抽象设计，通过工厂模式生成不同类型的序列化逻辑。
