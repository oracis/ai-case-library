## 它是干什么的

Divine Widgets 是一款面向基督教女性的小组件 App（TrustMRR 描述：Christian Bible Widget App for Women）。它把定制的圣经经文、祷告与基督教肯定句放到 iPhone 的桌面与锁屏上，把用户每一次解锁手机变成与神相遇的时刻；支持离线圣经、可自定义的桌面/锁屏小组件、每日提醒，无广告。2026-03-03 上架 App Store，评分 4.8/5，1 人团队、自筹资金，技术栈 React Native + Expo + Supabase + Vercel，支付走 Superwall。


## 钱从哪来

移动 App 订阅：锁屏/桌面小组件 + 每日经文推送，1 人运营。支付商 Superwall API 验证的口径是 MRR $1,254、近 30 天 $4,382、累计约 $16,591；标的叫价 $20,000。

## 它为什么能成

- 小组件把「用户不打开 App」这个致命问题绕开了：内容直接长在锁屏和桌面上，每天自动曝光一次。
- 垂直到「女性 + 圣经」这一格，应用商店里的竞争几乎为零，而这类人群的留存与付费动机来自每日仪式，不是功能多寡。
- 单人可维护：经文与配图是现成内容，不需要原创生产，边际成本近似为零。
- $20,000 叫价对应约 $1,254 的 MRR（约 1.3x），是典型的微收购区间——买家买的是一份不需要团队的现金流。

## 能搬走的部分

- 低频内容型 App 的解药是小组件：把打开率问题换成曝光位问题。
- 垂直到「人群 × 场景」的一格（女性 / 信仰 / 每日一句），比做通用版更容易在商店里被搜到。
- 信仰与情绪类产品的付费点是仪式感，不是内容量——每天一条比一百条合集更值钱。
- 单人、无团队依赖的小现金流资产在微收购市场是有流动性的：做不大，也卖得掉。
