## 它是干什么的

Avenue 做一个「科技票务 + 本地生活」平台：用户在里面订演出票、电影票和餐厅位，主办方与商家上架免手续费。官网自述定位是 tech-enabled ticketing / going-out platform——卖的不是「票务系统」，是「城市夜生活入口」。公司 2025 年 1 月才注册，一年半时间里近 30 天已验证收入冲到 $502,645，累计 $1,102,462。


## 钱从哪来

「主办方免费」是获客武器，钱在购票端收：平台向买家加收服务费（票务行业的标准打法，Dice 已验证）。TrustMRR 从支付网关 API 直读的收入口径包含全部过平台流水，非订阅制，MRR 恒 0——引用必须用「近 30 天已验证收入」并说明含一次性交易。

## 它为什么能成

- 「今晚干什么」是真实的高频决策，而现有产品把它拆得很碎：票在票务站、电影在影院 App、餐位在预订平台。Avenue 用一个入口收拢三种同类决策，用户端形成习惯后迁移成本极高。
- 对主办方零手续费直接打传统票务商的痛（对方通常收 2–5% + 单张固定费）。供给侧被免费策略快速撬动，需求侧跟着活动日历走。
- 收入过支付网关、可被 API 验证——在这个充满自报数字的行业里，「可验证」本身就是对买家与合作伙伴的信任资产。
- 一年半从 0 到 $110 万累计：说明本地夜生活供需两端都被它接上了，不是单城市的偶然数据。

## 能搬走的部分

- 选一个「离钱近 + 决策冲动强」的垂直行业做入口，别做通用平台。
- 供给侧免费（零手续费）撬动上架，需求侧收费——双边市场的经典补贴侧选择，关键是免费侧必须真是对方最疼的成本。
- 收入口径必须按交易流水报，且明说「随活动日历波动」；把波峰月份的数字当常态讲，是这个行业最常见的自欺。
- 上架即过支付网关，让每一笔收入可被第三方 API 验证。
